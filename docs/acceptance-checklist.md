# Чек‑лист приёмки проекта (Acceptance Checklist)
Чек‑лист фиксирует критерии готовности пет‑проекта «1C Service Center» (MVP) для демонстрации в портфолио.  
Каждый пункт — бинарная проверка: «да/нет».

## База и развёртывание
- [ ] Конфигурация успешно загружена из XML‑файлов в пустую базу 1С:Предприятие 8.3  
- [ ] Конфигурация обновлена в режиме «Предприятие» без ошибок  
- [ ] Справочники заполнены тестовыми данными (клиенты, сотрудники, виды работ, запчасти)  

## Учёт заявок и расчёт сметы
- [ ] Создан справочник «Клиенты» с контактными данными  
- [ ] Созданы справочники «Виды работ» и «Запчасти» с актуальными ценами  
- [ ] Реализован документ «Заявка на ремонт» со статусами: «Новая», «В работе», «Ожидание запчастей», «Готова», «Ожидает оплаты», «Закрыта»  
- [ ] При выборе работы или запчасти в табличной части автоматически подставляется цена из справочника  
- [ ] Сумма по строке (`Количество × Цена`) и общая сумма заявки пересчитываются автоматически  

## Складской учёт запчастей
- [ ] Создан регистр накопления «Остатки запчастей» (остатки)  
- [ ] Документ «Приход запчастей» корректно увеличивает остаток деталей на складе  
- [ ] При проведении заявки в статусе «Готова» запчасти списываются со склада; при нехватке деталей проведение блокируется с предупреждением  

## Взаиморасчёты с клиентами
- [ ] Создан регистр накопления «Взаиморасчёты с клиентами» (остатки)  
- [ ] При переводе заявки в статус «Ожидает оплаты» фиксируется задолженность клиента на сумму сметы  
- [ ] Документ «Оплата от клиента» уменьшает долг клиента и автоматически переводит заявку в статус «Закрыта»  

## Отчётность (СКД)
- [ ] Отчёт «Выручка и расходы» корректно считает поступления, затраты и прибыль за выбранный период  
- [ ] Отчёт «Остатки запчастей» показывает актуальное количество деталей на складе  
- [ ] Отчёт «Долги клиентов» отображает текущую задолженность по клиентам  

## Документация и контроль версий
- [ ] `README.md` содержит описание проекта, стек, функционал и инструкцию по запуску  
- [ ] Документация в папке `docs/` (`project-charter.md`, `requirements.md`, `task-breakdown.md`, `acceptance-checklist.md`) актуализирована  
- [ ] Актуальная конфигурация выгружена в XML-файлы и загружена в репозиторий GitHub
