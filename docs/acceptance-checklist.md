# Чек‑лист приёмки проекта (Acceptance Checklist)
Чек‑лист фиксирует критерии готовности пет‑проекта «1C Service Center» для демонстрации в портфолио
Каждый пункт — бинарная проверка: «да/нет»

## База и развёртывание
- [ ] Конфигурация успешно загружена из XML‑файлов в пустую базу 1С:Предприятие 8.3  
- [ ] Конфигурация обновлена в режиме «Предприятие» без ошибок
- [ ] Справочники заполнены тестовыми данными (клиенты, оборудование, мастера, номенклатура запчастей)

## Учёт клиентов и оборудования
- [ ] Создан справочник «Клиенты» с полями: ФИО/наименование, контакты, адрес  
- [ ] Создан справочник «Оборудование» с привязкой к клиенту, моделью и серийным номером  
- [ ] Реализован документ «Приёмка в ремонт» с выбором клиента и оборудования, фиксацией неисправности и даты приёма  

## Жизненный цикл заявки
- [ ] Реализован документ «Заявка на ремонт» со статусами: «Новая», «В работе», «Ожидание запчастей», «Готово», «Ожидает оплату», «Закрыто»  
- [ ] Статусы переключаются вручную через форму документа; история статусов фиксируется в регистре сведений  
- [ ] При статусе «Закрыто» автоматически фиксируется дата завершения и комментарий мастера

## Взаиморасчёты
- [ ] Создан регистр накопления «ВзаиморасчётыСКлиентами» (остатки)
- [ ] Реализован документ «Оплата от клиента» с проведением по регистру
- [ ] Стоимость закрытого заказа уменьшает долг клиента автоматически
- [ ] Отчёт «Долги клиентов» показывает остаток по каждому клиенту

## Учёт запчастей и расчёт стоимости
- [ ] Реализован регистр накопления «Остатки запчастей» (приход/расход)  
- [ ] В документе «Заявка на ремонт» есть табличная часть «Использованные запчасти» с автоматическим списанием из регистра  
- [ ] Реализован расчёт стоимости ремонта: сумма работ (ставка мастера × часы) + стоимость запчастей 

## Отчётность (СКД)
- [ ] Отчёт «Реестр заявок» с фильтрами по статусу, клиенту, дате приёма  
- [ ] Отчёт «Выручка по мастерам» с детализацией по заявкам и суммам  
- [ ] Отчёт «Остатки запчастей» с группировкой по номенклатуре и складу  

## Документация и контроль версий
- [ ] README.md содержит описание проекта, стек, функционал, инструкцию по запуску  
- [ ] Устав проекта (project‑charter.md) фиксирует цели, границы, критерии успеха, риски  
- [ ] Все изменения в конфигурации выгружены в XML и закоммичены в GitHub с осмысленными сообщениями
