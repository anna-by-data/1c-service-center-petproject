# Устав проекта: 1C Service Center

**Автор:** Парыгина Анна  
**Дата:** 05.11.2026  
**Статус:** Черновик

## Цель проекта
Разработать конфигурацию 1С для автоматизации работы сервисного центра по ремонту техники 
Цель — сократить время обработки заявки с 24 часов до 2 часов и автоматизировать расчёт стоимости ремонта

### Что входит в проект (In Scope)
1) Учёт клиентов и оборудования
2) Жизненный цикл заявки: Новая → В работе → Ожидание запчастей → Готово → Закрыто
3) Взаиморасчёты с клиентами (регистр накопления, документ «Оплата от клиента»)
4) Склад запчастей: приход/списание через регистры накопления
5) Расчёт стоимости ремонта (работы + запчасти)
6) Отчётность на СКД: выручка по периодам, долги клиентов, загрузка мастеров

## Вне границ проекта (Out of Scope)
1) Интеграция с мессенджерами/телефонией
2) Мобильное приложение
3) Личный кабинет клиента

### Критерии успеха (измеримые)
1) Оформление заказа по контрольному примеру ≤ 3 минут
2) Отчёт «Выручка по периодам» формируется ≤ 5 секунд на демо-данных
3) Долги клиентов видны в отчёте без ручного пересчёта
4) Проект сдан до 01.12.2026, трудозатраты не более 140 часов
5) Приёмка по чек-листу, самооценка по критериям ≥ 8/10

### Смета и сроки
- Оценка трудозатрат: ~120 часов
- Целевая дата сдачи: 01.12.2026

## Риски
- Несовместимость версий платформы 1С (требуется 8.3.20+)
- Большой объём тестовых данных может замедлить работу демо-базы
