# Устав проекта: 1C Service Center

**Автор:** Парыгина Анна  
**Дата:** 05.11.2026  
**Статус:** Черновик

## Цель проекта
Разработать конфигурацию 1С для автоматизации работы сервисного центра по ремонту техники 
Цель — сократить время обработки заявки с 24 часов до 2 часов и автоматизировать расчёт стоимости ремонта

## Границы проекта (In Scope)
1) Учёт клиентов и оборудования
2) Жизненный цикл заявки (приём → диагностика → ремонт → выдача)
3) Учёт запчастей (регистры накопления)
4) Отчётность (выручка, загрузка мастеров, сроки ремонта)

## Вне границ проекта (Out of Scope)
1) Интеграция с мессенджерами/телефонией
2) Мобильное приложение
3) Личный кабинет клиента

## Критерии успеха (Success Criteria)
1) Конфигурация разворачивается из файлов репозитория менее чем за 10 минут
2) Реализованы все статусы жизненного цикла заявки
3) Отчёт по выручке формируется автоматически на основе проведённых документов
4) В репозитории есть полная документация (README, устав, чек-лист)

## Риски
- Несовместимость версий платформы 1С (требуется 8.3.20+)
- Большой объём тестовых данных может замедлить работу демо-базы
