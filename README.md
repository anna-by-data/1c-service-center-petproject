# 1C Service Center — Пет-проект аналитика и разработчика 1С
**Автор:** Парыгина Анна  

## О проекте
Учебный пет-проект для портфолио: конфигурация на платформе «1С:Предприятие 8.3» для автоматизации базового учёта в сервисном центре по ремонту техники. 

Проект сфокусирован на реализации классического минимального функционала (MVP): приём заявок, автоматический расчёт сметы по прайс-листу, базовый складской учёт запчастей, фиксация оплат от клиентов и формирование управленческих отчётов.

## Стек технологий
* **Платформа:** 1С:Предприятие 8.3 (управляемые формы)
* **Отчётность:** Встроенная система построения отчётов 1С (на основе запросов)
* **Хранение метаданных:** Выгрузка конфигурации в XML-файлы
* **Контроль версий:** Git / GitHub

## Реализованный функционал (MVP)
1. **Справочники:** «Клиенты», «Сотрудники», «Виды работ» (прайс-лист), «Запчасти».
2. **Документ «Заявка на ремонт»:**
   * Ведение жизненных статусов заявки («Новая», «В работе», «Ожидание запчастей», «Готова», «Ожидает оплаты», «Закрыта»).
   * Автоматическая подстановка цен из справочников при выборе работ и запчастей.
   * Автоматический расчёт сумм по строкам и итоговой суммы сметы.
3. **Складской учёт (Регистр накопления «Остатки запчастей»):**
   * Поступление запчастей документом «Приход запчастей».
   * Списание использованных деталей при проведении заявки со статусом «Готова» с контролем остатков.
4. **Взаиморасчёты с клиентами (Регистр накопления «Взаиморасчёты с клиентами»):**
   * Начисление долга клиента при переводе заявки в статус «Ожидает оплаты».
   * Регистрация оплаты документом «Оплата от клиента» с автоматическим закрытием заявки.
5. **Управленческая отчётность:**
   * Отчёт «Выручка и расходы» за выбранный период.
   * Отчёт «Остатки запчастей» на складе.
   * Отчёт «Долги клиентов».

## Как запустить проект
1. Создайте пустую информационную базу в «1С:Предприятие 8.3».
2. Откройте Конфигуратор → **Конфигурация** → **Загрузить конфигурацию из файлов** и укажите папку с XML-файлами из репозитория.
3. Обновите конфигурацию базы данных (клавиша `F7`).
4. Запустите базу в режиме «1С:Предприятие» и заполните справочники тестовыми данными.
