# 1C Service Center — Пет-проект аналитика 1С
Автор: Парыгина Анна

## О проекте
Пет-проект для портфолио аналитика 1С. Автоматизация работы сервисного центра: учёт заявок, управление статусами, расчёт стоимости ремонта, формирование отчётности.

## Стек технологий
1) Платформа: 1С:Предприятие 8.3
2) Отчётность: Система компоновки данных (СКД)
3) Хранение метаданных: выгрузка конфигурации в XML-файлы
4) Контроль версий: GitHub

## Функционал
1) Учёт клиентов и оборудования на ремонте
2) Жизненный цикл заявки (статус от приёма до закрытия)
3) Учёт запчастей (приход/списание) через регистры накоплений
4) Отчёты по выручке и загрузке мастеров
5) Взаиморасчёты с клиентами и отчёт по долгам

## Как запустить
1) Выгрузить файлы конфигурации из репозитория в пустую базу 1С
2) Обновить конфигурацию базы данных
3) Заполнить справочники тестовыми данными
